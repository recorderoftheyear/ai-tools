# Partager du contexte avec un assistant IA

- Décrire la fonctionnalité, les rôles et les données dont le contrôle dépend.
- Remplacer les secrets, les identifiants et les données personnelles par des exemples fictifs.
- Demander à l’assistant de distinguer ses hypothèses des preuves observées.
- Vérifier le comportement attendu avec un test et conserver le résultat dans le projet.
